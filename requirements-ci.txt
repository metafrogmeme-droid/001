# Pinned dependencies for the CI test environment (.github/workflows/ci.yml).
# This mirrors the environment the known-failures baseline (tests/known_failures.txt)
# was generated in, so the baseline-diff gate is reproducible.
#
# IT MUST COVER EVERY MODULE requirements.lock PINS. That is now enforced by
# tests/test_ci_env_matches_lock.py, and this header is why.
#
# It used to end: "Optional, heavy, or import-guarded extras (anthropic,
# mplfinance/matplotlib/pandas) are intentionally omitted — their absence is
# part of the baseline." Every clause was true and the conclusion was backwards.
# `requirements.lock` says a module is GUARANTEED PRESENT in production; a CI
# environment that omits it tests a system nobody runs, and the omission is
# invisible because the tests that need it skip. Twenty chart tests skipped here
# on every green run for months while /chart quietly sent text.
#
# "Import-guarded" was the specific trap. Pillow is guarded at eleven sites and
# is not optional at all — a guarded import means the code SURVIVES the absence,
# not that the feature is expendable. Being heavy is a reason to cache the
# install, not to stop testing the feature.
#
# Every pin below is exact (`==`). This file has no `--hash` lines. pip treats
# any hash as `--require-hashes` for the whole file and then will not install
# a transitive that the file does not name. CI runs `pip install -r` this
# file, so a partial hash lock would break that install. The pip wheel in
# ci.yml and the Docker base image are hash-pinned and digest-pinned on their
# own.
