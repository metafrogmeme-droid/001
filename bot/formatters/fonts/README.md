# Fonts the bot's image cards draw with

`Inter-Regular.otf`, `Inter-Medium.otf`, `Inter-SemiBold.otf`, `Inter-Bold.otf`:
Inter 4, © 2016–2023 The Inter Project Authors (https://github.com/rsms/inter),
SIL Open Font License 1.1 (`LICENSE.OFL.txt`). Vendored so a card looks the
same on every box the bot runs on; the card renderer falls back to DejaVu Sans
when a file here cannot be opened, and to a CJK face for translated labels.
