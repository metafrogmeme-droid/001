Claw Watch

Claw Watch is advisory only. It is fail-open: if indexing lags or this site is down, there is no alert. It cannot stop a drain on its own.

This page never asks for a seed phrase, a private key, or for you to run code.

A revoke shown here is an unsigned transaction. Your wallet signs it and submits it. It does not depend on this site staying online. Nothing here is pre-signed, and this site does not relay it.

A cancel link applies once an on-chain module exists. None is installed, so there is no cancel transaction.
