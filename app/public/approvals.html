🩻 Allowance X-ray

The firewall's other half. The transaction X-ray warns you before a signature — this reads what your wallet has already granted: which contracts can spend your tokens right now, checked read-only against a short registry of well-known spenders. For every live grant it writes the exact revoke calldata — which your own wallet sends. This server never signs, never sends, never holds a key.

Check an address

What this is — and is not

Bounded by construction: only the curated majors on each chain are checked, and only against well-known spenders (Permit2, 1inch, 0x, Seaport, and — where its bytecode really is the router — Uniswap's SwapRouter02). Approvals to anything outside this registry are not scanned, so a clean result is never a guarantee. A pair that can't be read is counted as unreadable, never shown as zero. UNLIMITED means the grant exceeds 2¹²⁸ — the same threshold the transaction X-ray uses, so both halves of the firewall agree.
