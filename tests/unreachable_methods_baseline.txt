# Public METHODS in bot/ with no caller outside tests.

# Generated and enforced by tests/test_no_new_unreachable_functions.py
# (test_no_new_unreachable_methods). This is the THIRD granularity:
#
#   unreachable_baseline.txt            a module nobody imports
#   unreachable_functions_baseline.txt  a module-level def nobody calls
#   this file                           a METHOD nobody calls
#
# The gap was real and had already been paid for. LearningOrchestrator.
# process_proposals fell through both older checks — bot/learning/orchestrator.py
# IS imported so the module ratchet passed it, and a method is not a
# module-level def so the function ratchet never looked. It was public, on a
# class the engine constructs every run, with no caller, while four surfaces
# claimed proposals had been 'applied'. A human found it; no gate did.
#
# A RATCHET, BOTH DIRECTIONS, same rule as known_failures.txt: a new entry
# means somebody just wrote a method nobody calls, and an entry that leaves
# must be deleted in the same commit that wires it.
#
# KNOWN BLIND SPOT — THIS LIST IS AN UNDERCOUNT, AND BY AN UNKNOWN AMOUNT.
# The sweep counts IDENTIFIERS, so it cannot tell whose method a name refers
# to. When two classes define a method of the same name and either one is
# called, BOTH are acquitted. ComplianceEngine.format_for_telegram is the
# worked example: it has no caller anywhere, but seven other classes define
# `format_for_telegram` and telegram_handler.py calls it on `signal_tracker`,
# so this file has never listed it. The false direction matters — a missing
# accusation is silent, where a wrong one is loud and gets fixed.
#
# Recorded rather than repaired because narrowing it needs type inference the
# sweep does not have, and a gate whose coverage is overstated in prose is the
# failure this repo spends most of its guard tests preventing. Read the count
# below as a floor, not a total.
#
# THESE ARE RECORDED, NOT TRIAGED. A fan-out that classified all of them was lost
# when the container re-provisioned mid-run, and inventing the categories
# afterwards would be exactly the kind of confident claim from absent
# evidence this repo has a table about. What follows is grouped by what can
# be established mechanically — a name shaped like a control, a body
# carrying a known defect shape — and nothing else is asserted.

# it was fixed and wired, where an empty bucket seeded with 0.0 made it name
