# Every REGISTERED Telegram command and the GATE SPELLINGS it carries.
#
# The companion to `guarded_commands_baseline.txt`, which records what IS
# guarded and is therefore silent about a command that carries NO gate. Both
# ratchets then acquit it by omission, inside the pair whose own header says
# "a guard that silently disappears is an auth regression nothing else
# notices". Driven on 2026-09-18, four commands were in exactly that state.
#
# TWO-WAY, the `known_failures.txt` rule: a row that changes must be re-recorded
# in the same commit, a command that leaves must be deleted here, and a command
# that arrives must be added. A `none` row REQUIRES a reason after the `#`, and
# `unresolved` is never acceptable — it means this walk could not find the
# handler, which is a gate nobody measured rather than a gate that is absent.
#
# The vocabulary is hand-written and `tests/command_gates.py` says why that is
# safe: a spelling it does not know reads as `none`, which demands a reason, so
# an unrecognised gate is LOUD rather than an acquittal.
