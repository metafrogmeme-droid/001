# Test FILES that reach the network, and a RATCHET over them.
#
# A file NOT listed here that makes an outbound connect is a HARD FAILURE, by
# name, at that test's teardown. A file listed here still has its connects
# REFUSED — nothing here reaches a venue — and its count is printed at the end
# of every run so the backlog stays visible.
#
# ── why this exists, and why it is a backlog rather than a sweep ───────────
#
# tests/conftest.py refuses every outbound connect the suite makes. It shipped
# enforcing hard, on a measurement of twelve tests in four files — taken on a
# box whose HTTPS_PROXY is http://127.0.0.1:33283, where the reading answered
# `local` for the proxy and ALLOWED it. Every proxied venue read went out
# through loopback and was never seen; the twelve it did find are the ones
# that connect by raw IP and bypass the proxy, which is why the set looked
# plausible. CI has no proxy, connects direct, and reported SEVENTY-FOUR.
#
# Stubbing that many seams across these files is the wholesale conversion
# CLAUDE.md refuses, so the set is recorded and the growth direction enforced.
# Each row is a stub that was never made — not a test that needs the network.
#
# ── keyed by FILE, and the stale half is NOT enforced ──────────────────────
#
# Driven in CI, 60 of the 74 PASSED when re-run alone: the set is
# order-dependent, so a nodeid baseline would churn run to run and its stale
# direction would be a flake generator. A file is the stable unit, and GROWTH
# is the direction that matters — it can only fire when something new appears.
# Re-measuring the stale half is a deliberate act (drop a row, run the suite,
# see whether it comes back), not a gate. A gate whose coverage is overstated
# is the failure this repo is organised around; the limit is written down
# rather than left to be discovered.
#
# ── the four files that are NOT here ───────────────────────────────────────
#
# test_scan_reads_the_executors_record.py, test_monitor_liveness.py,
# test_monitor_one_broken_check_does_not_silence_the_rest.py and
# test_networth_gateway.py were stubbed when the containment landed. The
# monitor one is back below: its outbound-stage stub covers `run()`, and CI
# found a second reader the local measurement could not see.
#
