# Reads of an idea-like `.confidence` that do NOT go through
# `bot.core.signal_confidence.displayed_confidence`, each with its reason.
#
# TWO-WAY, as `known_failures.txt` is: a new site fails by name on every run, a
# listed site the rule no longer finds fails too, and the COUNTS must match, so
# a second site inside a listed file is not acquitted by the row already there.
# A row with no reason fails.
#
# The rule covers the two shapes the defect took: a PERCENT-formatted display
# (what a caller is told the confidence is) and a COMPARISON against a bar
# (what a gate does about it). An internal read that neither prints nor gates is
# not in the class -- `risk_engine`'s own arithmetic, the four decision-row
# writers, the flight recorder -- because handing a field onward under its own
# name is the opposite of re-deriving what it means.
#
# The receiver is judged by NAME, which over-reports by construction: every row
# below is a different quantity that happens to share the word. Narrowing by
# TYPE would mean guessing a type from a name, so the over-report is answered by
# a reason rather than by a cleverer regex.
#
# format: path  kind  reason        (one row per site)
#
bot/backtest/runner.py  pct  a BacktestTrade in the backtest's own report; the backtest applies no calibration curve
bot/core/explainability.py  pct  an ExplainabilityReport's own confidence field, not a TradeIdea's
bot/core/explainability.py  pct  the same report, the same field, one line of its own further down
bot/learning/reflection.py  pct  a recorded decision row's own figure, quoted back in the reflection it belongs to
bot/learning/reflection.py  pct  the same row's figure in the sibling sentence of the same reflection
bot/learning/reflection.py  cmp  the same row again: the reflection describes what was recorded, not what an idea claims now
bot/learning/strategy_eval.py  cmp  a recorded trade row read back for strategy evaluation, not a live idea
bot/skills/skill_registry.py  pct  a PATTERN's own confidence (PatternsSkill), which no calibration curve touches
#
# Receivers the rule no longer judges by name. Each is a different quantity
# that shares the word, and the rule makes it LOUD rather than acquitting it.
bot/core/divergence.py  cmp  two DivergenceSignals ranked by the detector's own pattern confidence, which no curve or nudge touches
bot/core/engine.py  cmp  a QualityReading (`_q = quality_reading(idea)`): the reading displayed_confidence itself asks, tested for None
bot/core/liquidity_sweep.py  cmp  two SweepSignals ranked by the detector's own confidence
bot/core/smart_money.py  cmp  the order-flow composite's own confidence, not an idea's
bot/learning/strategy_eval.py  cmp  a rejected-trade row read back for evaluation (`r` in `rejected`), not a live idea
bot/nlp/chat_facade.py  cmp  an IntentResult: the router's classification confidence, not a trade's
bot/nlp/intent_router.py  cmp  the router grading its own IntentResult (the 0.8 dispatch bar)
bot/nlp/intent_router.py  cmp  the same IntentResult at the router's 0.5 clarification bar
bot/risk/ladder_shadow.py  cmp  a ladder verdict's own reading, recorded; the verdict came from quality_reading
bot/risk/quality_ladder.py  cmp  the QualityReading this module defines, tested for None where it is built
bot/risk/quality_ladder.py  cmp  the same reading against a rung's floor: the ladder's own gate on its own reading
bot/risk/quality_ladder.py  cmp  the same reading tested for None where the Kelly factor reads it
bot/skills/telegram_handler.py  cmp  an IntentResult at the 0.8 dispatch bar, not a trade's confidence
bot/skills/telegram_handler.py  cmp  an IntentResult at the 0.5 clarification bar
bot/web/user_gateway.py  cmp  an IntentResult at the 0.8 dispatch bar (the web chat turn)
bot/web/user_gateway.py  cmp  an IntentResult at the 0.8 bar, a second branch of the same turn
bot/web/user_gateway.py  cmp  an IntentResult at the 0.8 bar, a third branch
bot/web/user_gateway.py  cmp  an IntentResult at the 0.8 bar, a fourth branch
bot/web/user_gateway.py  cmp  an IntentResult at the 0.8 bar, a fifth branch
bot/web/user_gateway.py  cmp  the public chat turn's IntentResult (`_pub_intent`) at the 0.8 bar
