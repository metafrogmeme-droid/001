# Every read of `opened_at` in bot/ outside `position_telemetry.entered_at`.
#
# `opened_at` is when the ORDER was placed. A limit entry can rest for hours
# before it fills, so a HOLD, an age or a time exit read from it counts time
# the position did not exist. Those read `entered_at(pos)`, which is the fill
# time when one is recorded. What remains here reads placement ON PURPOSE, or
# reads a book whose fills are immediate. Each row is
#     <path>::<qualname> <reads> | <reason>
# and the rule is two-way: a function that reads `opened_at` and is not listed
# fails, a listed function that no longer reads it fails, and the COUNT must
# match, so a new hold computed inside a listed function is not acquitted by
# the reads already there.
