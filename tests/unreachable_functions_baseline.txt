# Public module-level functions in bot/ with no caller outside tests.

# Generated and enforced by tests/test_no_new_unreachable_functions.py. The
# MODULE ratchet (unreachable_baseline.txt) cannot see these: their modules are
# imported by production code and pass it cleanly. This is that same check one
# level down.
#
# A RATCHET, BOTH DIRECTIONS. A new entry means somebody just wrote a function
# nobody calls. An entry that leaves — because you wired it — must be deleted in
# the same commit, or test_the_baseline_has_no_stale_entries fails. Same rule as
# known_failures.txt, for the same reason.
#
# Decorated functions are excluded from the scan entirely: a decorator is a
# registration, and reporting `@lab_router.get`-mounted handlers as dead is the
# false accusation the module checker's docstring warns about. This list is also
# a LOWER BOUND — a name defined in two modules is skipped rather than guessed at.
#
# Sorted by how uncomfortable each group is to find here.
