BotChainSeal

Live product

Deployed and reachable today. No hackathon submission is claimed for it.

Commits a file's hash to BOT Chain, and lets anyone check it without a wallet.

BotChainSeal stores a hash on BOT Chain mainnet (chain id 677). The contract keeps the hash, not the file. A read-only page hashes a file in your browser and reads the contract: nothing is uploaded and no wallet is asked for.

It began on Bohr, BOT Chain's testnet, which is why the verifier's address still carries that name. Bohr and BotChainSeal are one project, listed once.

The first evidence it sealed records a session on Somnia testnet (chain id 50383), a different network. The hash is on BOT Chain; the session was not.
