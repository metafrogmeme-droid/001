HashKey Seal

Live product

Deployed and reachable today. No hackathon submission is claimed for it.

Anchors RUNECLAW's sealed receipts as hashes on HashKey Chain.

RUNECLAW seals agent calls and receipts as hashes. HashKeySeal stores each hash on HashKey Chain with the publisher that anchored it and its kind. It accepts no value, has no function that sends value, and is not upgradeable.

The contract is deployed on HashKey Chain mainnet (chain id 177), and the explorer reports its source as verified. A mainnet deploy is done by the owner by hand: no server path signs on that chain.
