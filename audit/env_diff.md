# Environment variable audit

Method: every call shaped `<env-helper>("VAR")` across .py/.js/.mjs/.ts/.sh,
where `<env-helper>` is one of the 16 accessors this repo defines, plus the
`os.environ[...]` and `process.env.*` forms. The reverse direction additionally
requires the name to appear NOWHERE in the tree, because several vars are read
indirectly through provider lookup tables (`ALIBABA_API_KEY` is passed as a
string, never to `os.getenv`) — a naive diff reports those as dead and is wrong.
